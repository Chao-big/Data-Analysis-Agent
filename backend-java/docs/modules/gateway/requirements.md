# Java Gateway 模块需求

## 1. 模块定位

`gateway` 模块是前端访问 Java 单体的聚合入口边界，负责工作台 bootstrap 数据和健康检查。

## 2. 当前代码现状

当前仅存在 `GET /api/gateway/health` 骨架接口。MVP 需要把它扩展为工作台 BFF。

## 3. 核心职责

1. 对前端暴露统一健康检查。
2. 聚合工作台初始化所需数据。
3. 屏蔽内部 Java 模块细节。
4. 提供轻量 bootstrap 响应。

## 4. MVP 功能需求

1. 提供首页 bootstrap 数据接口。
2. 统一封装前端常用聚合响应。
3. 统一透传 `traceId`。

## 5. 边界约束

1. 不承载核心业务规则。
2. 不直接执行分析。
3. 不直接生成权限上下文。
4. 初版不负责长任务流转发。
5. 初版任务 SSE 由 `job` 模块的 `/api/tasks/{id}/stream` 承接。

## 6. 验收标准

1. 前端只依赖少量聚合接口即可完成工作台初始化。
2. 前端可以通过该模块感知后端健康状态。
3. bootstrap 响应可以减少首页首次并发请求数量。
