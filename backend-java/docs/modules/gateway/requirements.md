# Java Gateway 模块需求

## 1. 模块定位

`gateway` 模块是前端访问 Java 单体的统一入口边界，负责聚合首页初始化数据、对外暴露健康检查和承接 SSE 出口。

## 2. 当前代码现状

当前仅存在 `GET /api/gateway/health` 骨架接口。MVP 需要把它扩展为工作台 BFF。

## 3. 核心职责

1. 对前端暴露统一健康检查
2. 聚合工作台初始化所需数据
3. 承接任务 SSE 流式输出
4. 屏蔽内部 Java 模块与 Python 模块细节

## 4. MVP 功能需求

1. 提供首页 bootstrap 数据接口
2. 提供任务 SSE 订阅出口
3. 统一封装前端常用聚合响应
4. 统一透传 `traceId`

## 5. 边界约束

1. 不承载核心业务规则
2. 不直接执行分析
3. 不直接生成权限上下文

## 6. 验收标准

1. 前端只依赖少量聚合接口即可完成工作台初始化
2. SSE 可以从 Java 层稳定输出到前端
3. 前端可以通过该模块感知后端健康状态
