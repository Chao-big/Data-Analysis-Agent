# Python Tool Chart 模块需求

## 1. 模块定位

`tool_chart` 负责把分析结果转换为前端可直接渲染的图表配置。

## 2. 当前代码现状

当前仅实现 `build_line_chart(title)`，并返回固定月份数据的折线图配置。

## 3. 核心职责

1. 根据结果集选择合适图表类型
2. 构建 ECharts 或等价配置对象
3. 返回标题、轴、系列和必要说明

## 4. MVP 功能需求

1. 支持折线图
2. 支持柱状图
3. 支持饼图
4. 支持空结果集降级处理
5. 支持对图表标题进行业务语义化命名

## 5. 输入输出要求

输入至少包括：

1. 问题文本
2. 查询结果
3. 推荐图表类型

输出至少包括：

1. `title`
2. `xAxis`
3. `yAxis`
4. `series`

## 6. 验收标准

1. 前端可以直接渲染生成的图表配置
2. 图表与问题语义一致
3. 空数据时不会抛出异常
