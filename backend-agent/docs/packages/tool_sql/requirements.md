# Python Tool SQL 模块需求

## 1. 模块定位

`tool_sql` 是数据分析 Agent 的核心工具模块，负责把自然语言问题转成只读 SQL，并在约束条件下执行查询。

## 2. 当前代码现状

当前仅有 `build_read_only_sql(question)`，返回固定 SQL 和简单 reason，尚未接入真实 Schema、真实执行器和风控细节。

## 3. 核心职责

1. 基于问题和 Schema 生成 SQL
2. 保证 SQL 只读
3. 校验访问表范围
4. 执行查询并返回结构化结果

## 4. MVP 功能需求

1. 支持按数据集 Schema 生成 `SELECT` 语句
2. 支持多种常见聚合分析问题
3. 支持只读 SQL 校验
4. 支持执行超时和返回行数限制
5. 支持返回 SQL 理由和执行摘要

## 5. 风险控制要求

1. 禁止 DDL、DML
2. 禁止未授权表访问
3. 禁止多语句执行
4. 超出最大结果行数时自动截断或拦截

## 6. 验收标准

1. 常见趋势分析问题能生成可执行 SQL
2. 非法 SQL 能被明确拦截
3. 查询结果能被后续 Python 分析和图表工具消费
