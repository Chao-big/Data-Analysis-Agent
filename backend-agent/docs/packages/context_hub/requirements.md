# Python Context Hub 模块需求

## 1. 模块定位

`context_hub` 负责构建任务执行上下文，把任务请求、数据集信息、权限边界和分析约束整理成 Agent 可消费的统一输入。

## 2. 当前代码现状

当前 `build_context(request)` 只返回：

1. `task_id`
2. `question`
3. `dataset_ids`

还缺少 Schema、权限和提示增强信息。

## 3. 核心职责

1. 汇总任务请求
2. 装配数据集元数据
3. 装配最小权限上下文
4. 输出给 Planner 和 Tool 层使用

## 4. MVP 功能需求

1. 合并任务请求和数据集摘要
2. 注入数据集字段信息
3. 注入角色和可访问表范围
4. 注入脱敏字段信息
5. 输出统一上下文字典

## 5. 验收标准

1. Planner 不需要单独再访问多个来源拼上下文
2. SQL 工具能基于该上下文做授权校验
3. 上下文可稳定复用到日志和审计
