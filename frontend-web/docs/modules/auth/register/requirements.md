# 注册界面元素需求

## 1. 目的

`/register` 是项目的注册入口，负责创建新的登录账号并在成功后回到登录页。

当前前端版本先做基础防刷与格式校验，后续仍需要由 Java 后端做最终校验与落库。

## 2. 依据

- `infra/mysql/schema/20260827_auth_tables.sql`
- `frontend-web/agent.md`
- `frontend-web/src/pages/RegisterPage.vue`
- `frontend-web/src/lib/register-validation.ts`

## 3. 页面必须包含的元素

1. 页面标题
2. 用户名输入框
3. 邮箱输入框
4. 手机号输入框
5. 密码输入框
6. 确认密码输入框
7. 注册按钮
8. 错误提示区
9. 登录跳转入口

## 4. 字段规则

### 4.1 用户名

- 必填
- 至少 3 个字符
- 用于后续登录
- 当前页面仅做长度校验

### 4.2 邮箱

- 必填
- 必须符合常见邮箱格式
- 示例：`name@example.com`

### 4.3 手机号

- 必填
- 必须符合中国大陆 11 位手机号格式
- 需满足 `1[3-9]xxxxxxxxx`

### 4.4 密码

- 必填
- 至少 8 位
- 至少包含 1 个小写字母
- 至少包含 1 个大写字母
- 至少包含 1 个特殊字符

### 4.5 确认密码

- 必填
- 必须与密码一致

## 5. 交互要求

1. 用户离开输入框后应触发该字段校验
2. 字段已被标记为无效后，继续输入时应实时重新校验
3. 校验失败的输入框应显示红色错误态
4. 表单底部应显示当前优先命中的错误提示
5. 提交时必须再次校验全部字段
6. 校验未通过时不得继续提交

## 6. 提交行为

1. 校验通过后才允许进入提交态
2. 当前版本点击注册按钮不会请求真实后端
3. 当前版本调用前端本地 `registerMockAccount`
4. 注册成功后跳转到 `/login?registered=1&identifier=<username>`

## 7. 非目标

- 姓名字段
- 图形验证码
- 短信验证码
- SSO
- 多因素认证
- 邀请码
